# Referencias do Code Playback

Materiais visuais e textuais usados para definir o componente Code Playback.

## Materiais

- `example-code-block.txt`: exemplo de bloco de codigo usado como ponto de partida.
- `prd-example.txt`: exemplo de estrutura de PRD fornecido para a especificacao.
- `playback-case-01.png`: Contains Duplicate, com loop aninhado.
- `playback-case-02.png`: Valid Anagram, com abordagem de ordenacao.
- `playback-case-03.png`: Two Sum, com abordagem brute force.
- `playback-case-04.png`: Group Anagrams, com Hash Map e chaves ordenadas.
- `playback-case-05.png`: Top K Frequent Elements, com abordagem de ordenacao.
- `playback-case-06.png`: Encode and Decode Strings, com prefixo de tamanho.
- `playback-case-07.png`: Products of Array Except Self, com construcao do resultado.
- `playback-case-08.png`: Valid Sudoku, com validacao por Hash Set.
- `playback-case-09.png`: Longest Consecutive Sequence, com Hash Set.
- `playback-case-10.png`: Valid Palindrome, com dois ponteiros.
- `line-highlight.png`: destaque da linha de codigo sincronizado com o playback.
- `layout-default.png`: layout padrao, com controles e estado acima do codigo.
- `layout-control.png`: controle para alternar a visualizacao expandida.
- `layout-expanded.png`: layout expandido, com estado e codigo lado a lado.
