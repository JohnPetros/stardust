# Code Playback References

Visual and textual materials used to define the Code Playback component.

## Materials

- `example-code-block.txt`: example code block used as a starting point.
- `prd-example.txt`: example PRD structure provided for the specification.
- `playback-case-01.png`: Contains Duplicate, with a nested loop.
- `playback-case-02.png`: Valid Anagram, with a sorting approach.
- `playback-case-03.png`: Two Sum, with a brute force approach.
- `playback-case-04.png`: Group Anagrams, with a Hash Map and sorted keys.
- `playback-case-05.png`: Top K Frequent Elements, with a sorting approach.
- `playback-case-06.png`: Encode and Decode Strings, with a length prefix.
- `playback-case-07.png`: Products of Array Except Self, with result construction.
- `playback-case-08.png`: Valid Sudoku, with Hash Set validation.
- `playback-case-09.png`: Longest Consecutive Sequence, with a Hash Set.
- `playback-case-10.png`: Valid Palindrome, with two pointers.
- `line-highlight.png`: code line highlight synchronized with the playback.
- `layout-default.png`: default layout, with controls and state above the code.
- `layout-control.png`: control to toggle the expanded view.
- `layout-expanded.png`: expanded layout, with state and code side by side.
